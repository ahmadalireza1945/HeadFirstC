DAFTAR STRUKTUR DATA UNTUK BELAJAR C
====================================

Catatan:
- Tidak ada daftar yang benar-benar final karena varian terus berkembang.
- Daftar ini mencakup struktur data yang paling umum dipelajari dan sering dipakai.

1) LINEAR DASAR
---------------
1. Array (static array)
2. Dynamic Array (resizable array, vector-style)
3. String (char array)
4. Singly Linked List
5. Doubly Linked List
6. Circular Linked List
7. Unrolled Linked List
8. XOR Linked List

2) AKSES TERBATAS
-----------------
1. Stack (LIFO)
2. Queue (FIFO)
3. Circular Queue
4. Deque (double-ended queue)
5. Priority Queue (abstract form)
6. Monotonic Queue
7. Ring Buffer (Circular Buffer)

3) HASH DAN PEMETAAN
--------------------
1. Hash Table
2. Hash Map (key-value)
3. Hash Set
4. Ordered Map (biasanya berbasis tree)
5. Multimap
6. Multiset
7. Symbol Table

4) HIMPUNAN DISJOINT
--------------------
1. Disjoint Set Union (DSU / Union-Find)

5) HEAP DAN VARIANNYA
---------------------
1. Binary Heap (Min-Heap / Max-Heap)
2. Binomial Heap
3. Fibonacci Heap
4. Pairing Heap
5. Leftist Heap
6. Skew Heap
7. d-ary Heap

6) TREE UMUM
------------
1. General Tree (N-ary Tree)
2. Binary Tree
3. Full Binary Tree
4. Complete Binary Tree
5. Perfect Binary Tree
6. Threaded Binary Tree

7) BALANCED SEARCH TREE
-----------------------
1. Binary Search Tree (BST)
2. AVL Tree
3. Red-Black Tree
4. Splay Tree
5. Treap
6. AA Tree
7. Scapegoat Tree
8. Weight-Balanced Tree

8) MULTIWAY SEARCH TREE
-----------------------
1. B-Tree
2. B+ Tree
3. B* Tree
4. 2-3 Tree
5. 2-3-4 Tree

9) TREE UNTUK RANGE/QUERY
-------------------------
1. Segment Tree
2. Lazy Segment Tree

4. Interval Tree
5. Range Tree
6. Order Statistic Tree

10) TRIE DAN STRING INDEX
-------------------------
1. Trie (Prefix Tree)
2. Compressed Trie

4. Ternary Search Tree
5. Suffix Tree
6. Suffix Array
7. LCP Array

3. Undirected Graph
4. Weighted Graph

2. QuadTree
3. Octree
